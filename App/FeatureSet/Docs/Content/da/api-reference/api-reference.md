# API Reference

Cast Operations leverer en omfattende REST API, der giver dig mulighed for at integrere overvågning, incident management og statussidesfunktionalitet i dine applikationer og arbejdsgange. **Alt, hvad du kan gøre på Cast Operations-dashboardet, kan også gøres via API'en, hvilket muliggør automatisering og brugerdefinerede integrationer.**

### Kom i gang

Vores API er organiseret omkring REST-principper og bruger standard HTTP-svarkoder, autentificering og verber. Alle API-endpoints returnerer JSON-svar.

### Autentificering

Alle API-anmodninger kræver autentificering ved hjælp af API-nøgler. Du kan generere API-nøgler fra dit Cast Operations-dashboard under Indstillinger > API-nøgler.
