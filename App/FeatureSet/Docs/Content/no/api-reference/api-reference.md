# API-referanse

Cast Operations tilbyr et omfattende REST API som lar deg integrere overvåking, hendelseshåndtering og statusidefunksjonalitet i applikasjonene og arbeidsflytene dine. **Alt du kan gjøre på Cast Operations-dashbordet kan også gjøres via API-et, noe som muliggjør automatisering og egendefinerte integrasjoner.**

### Kom i gang

API-et vårt er organisert rundt REST-prinsipper og bruker standard HTTP-responskoder, autentisering og verb. Alle API-endepunkter returnerer JSON-svar.

### Autentisering

Alle API-forespørsler krever autentisering med API-nøkler. Du kan generere API-nøkler fra Cast Operations-dashbordet ditt under Innstillinger > API-nøkler.
