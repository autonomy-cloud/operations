# Helm Chart for Cast Operations

This repository is used to host all the helm-charts for Cast Operations.

### Helm Packages 

- *oneuptime* : Chart for deploying Cast Operations app. [Read Docs here](oneuptime/README.md)
- *kubernetes-agent* : Chart for installing the Cast Operations Kubernetes monitoring agent into any cluster (standard, GKE Autopilot, EKS Fargate). [Read Docs here](kubernetes-agent/README.md)
